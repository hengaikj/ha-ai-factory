# reverse-skill 思路接入说明

状态：PROPOSED，尚未形成正式采用批准。

本项目采用 reverse-skill 的治理思想，不复制其全量工具链：

1. 任务先经过确定性路由；未知任务默认人工分诊。
2. 工作项、允许路径、禁止路径、基线和验收 ID 结构化记录。
3. 路由结果只描述所需范围，不产生权限。
4. 示例模板不能转化为审批；候选分支不能自我批准。
5. 产品 Contract、Java 服务、Vue 前端、数据库和 Agent Runtime 保持原边界。
6. 后续动作门禁、证据完整性和可信 CI 必须在独立工作项中实现和复审。

当前候选基线为 `cd9d73768de2cccd207b1eb7139bf5036c0fcca2`，尚待负责人接受。当前新增工具仅为离线 Python 标准库实现，不调用模型、Laya、Runtime、Git/CI 或外部服务。
