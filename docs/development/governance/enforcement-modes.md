# 治理强制模式配置

当前开发阶段配置为 `advisory`。治理 CLI 和 CI 可以运行并输出结果，但检查失败不会自动阻止合入，独立 Reviewer 和最小审批数暂不强制。该模式用于积累误报、补充证据和验证流程。

切换为 `strict` 前，需要负责人接受治理基线、独立 Reviewer 复审、完成一次通过和一次失败的 CI 阻断演练，并保存分支保护配置证据。切换只修改 `.agent/governance/enforcement.json`，不改变产品 Contract 或 Runtime 权限。

无论模式如何，以下动作始终失败关闭：真实模型/Runtime 调用、工具副作用、数据库迁移、部署和未授权合入。`advisory` 只放宽研发阶段的报告性检查，不授予这些动作权限。
